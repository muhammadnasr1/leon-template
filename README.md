# Leon Template - HTML Structure

هذا المشروع عبارة عن بناء الهيكلية الأساسية (HTML Structure) لقالب **Leon** كما تم شرحه في المحاضرة، تمهيداً لتنسيقه باستخدام CSS في المراحل القادمة.

## أقسام الصفحة (Page Sections)
تم تقسيم الكود وتنظيمه باستخدام التعليقات (`Comments`) إلى 7 أقسام رئيسية:
- **Header (`<header>`):** يحتوي على الشعار (`logo`)، أيقونة القائمة، وروابط التنقل الداخلي المرتبطة بأقسام الصفحة.
- **Landing (`.landing`):** القسم الترحيبي ويضم العنوان الرئيسي (`<h1>`) وفقرة تعريفية.
- **Features (`#features`):** يضم 3 بطاقات للمميزات باستخدام أيقونات مكتبة **Font Awesome**.
- **Services (`#services`):** مقسم إلى 3 أعمدة (`.col`) لعرض الخدمات الأربعة وصورة القسم.
- **Portfolio (`#portfolio`):** يعرض 3 مشاريع سابقة بالصور والوصف.
- **About (`#about`):** قسم تعريفي ينقسم إلى صورة ونصوص يفصل بينهما خط أفقي (`<hr>`).
- **Contact (`#contact`):** يضم بيانات التواصل، رابط البريد الإلكتروني، وأيقونات منصات التواصل الاجتماعي.
